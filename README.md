# Humans

Telegram Mini App для поиска интересных каналов и знакомства с людьми по интересам. Пользователь открывает приложение прямо внутри Telegram, листает категории каналов, заходит в карточку канала и при желании добавляет собственную анкету в раздел «Люди».

Это первый рабочий каркас (MVP) по техническому заданию из issue #1.

## Стек

Приложение построено на Next.js 14 (App Router) и TypeScript. Интерфейс — Tailwind CSS с набором компонентов в стиле shadcn/ui, анимации на Framer Motion, фоновая графика на Three.js. Визуальный язык повторяет Telegram: чёрный как основной цвет, синий как акцент, без лишнего декора. Интеграция с Telegram сделана через официальный `telegram-web-app.js`, который отдаёт данные пользователя для экрана профиля.

## Что реализовано

Главный экран показывает четыре категории: Криптовалюта, Новости, Профессиональный блог и Блог. Внутри категории — список каналов с аватаром, числом подписчиков и тегами региона (CIS / GLOBAL). Карточка канала открывает экран с описанием, нишей, количеством подписчиков и кнопкой перехода в Telegram.

Раздел «Люди» содержит анкеты и кнопку «+» в правом верхнем углу: по ней открывается форма, где можно указать имя, цель и интересы, после чего анкета попадает в список. Профиль берёт имя, username и аватар из Telegram (эти поля нередактируемы — так задумано). Настройки переключают язык интерфейса (русский / английский) и содержат контакты разработчика `@imnotsheikh` и официальный канал `@skenvco`.

## Запуск

```bash
npm install
npm run dev
```

Приложение поднимется на `http://localhost:3000`. Для полноценной проверки внутри Telegram нужен публичный HTTPS-адрес (например, через туннель или хостинг), который указывается боту в `@BotFather` как URL Mini App. Вне Telegram приложение тоже работает — профиль в этом случае показывает гостевое состояние.

## Структура

```
src/
  app/            маршруты: главная, категория, канал, люди, профиль, настройки
  components/     UI-примитивы (ui/), карточки, навигация, фон на Three.js
  lib/            данные, утилиты, локализация, обёртка Telegram, стор
  types/          общие типы
```

## Что пока замокано

Каналы и анкеты людей берутся из локального файла `src/lib/data.ts`, а добавленные анкеты живут только в текущей сессии. Реальное наполнение требует бэкенда: парсинг аватарок и описаний каналов по `@username`, панель администратора для добавления каналов и хранилище для анкет. Это следующий этап. Расширение профиля (интересы и ниши пользователя) тоже отложено по ТЗ.
